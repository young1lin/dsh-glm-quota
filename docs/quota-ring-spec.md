# 额度圆环界面规格

## 范围

收起侧栏、展开侧栏的状态胶囊、详情浮层共用一套凹槽圆环视觉。只修改 `client.js` 的渲染与倒计时刷新节奏；宿主额度数据、请求节流/退避、窗口分类及原有五档用量配色不变。

## 收起侧栏

- 每个令牌额度窗口各显示一枚 46px 圆环。顺序保持宿主返回的 5 小时、周额度（若有）及其他令牌窗口。MCP 不单独出现在收起栏；只有 MCP 时保留单环回退显示。
- 彩色弧长表示**已用比例**，按 0–100% 截断。真正的 0% 不绘制虚假的彩色起始弧；灰色凹槽仍然可见。
- 任何大于 0 的已用比例至少绘制 4% 周长的弧。1% 对应 3.6°，在 3–5px 凹槽上看不见，会让刚开始用的窗口显示成一个坏掉的空圈；下限只影响弧长，百分比数字与无障碍名称始终是真实值。
- 凹槽轨道使用 `--dsh-glm-track`（在宿主 `--dsw-alias-border-l2` 基础上混入三级标签色加深），不再直接用发丝边框色，否则整枚环在低用量时读起来像描边而非量表。
- 圆环中心显示该窗口距离重置的时间；无重置时间时留空。中心没有刷新图标、窗口名和百分比，环下也不重复显示倒计时。
- 精确百分比、窗口名、绝对重置时间以及数据过期提示放在悬停/聚焦说明和按钮的无障碍名称中。环弧与倒计时无需悬停即可看见。
- 保留点击刷新与键盘焦点样式。

## 展开侧栏

- 42px 状态胶囊中的 22px 环、详情浮层每行的 28px 环和收起栏的 46px 环使用相同的凹槽轨道、内盘高光和五档配色。只有收起栏的环内放倒计时。
- 详情浮层标题显示套餐档位：`Coding Plan · Max 额度`。档位取宿主投影的 `planLevel`（上游 `data.level`，与胶囊上的档位同源）；为空时退回 `Coding Plan 额度`，不留下孤立的分隔符。
- 详情中保留窗口标签、文字倒计时、令牌额度的精确百分比、MCP 的已用/上限次数。周额度和其他窗口的条件渲染与顺序不变；手动刷新及陈旧数据提示不变。

## 时间行为

- `resetAt <= 0` 表示重置时间未知，不显示倒计时。
- 剩余时间低于 60 秒时显示整数秒（`59s` 至 `1s`）；达到 60 秒时沿用分钟/小时/天简写。正剩余时间按秒向上取整，避免重置时间尚未到达时提前显示 `0s`。
- 次级单位为零时省略：显示 `1d`、`23h` 而不是 `1d0h`、`23h0m`。零值不携带信息，而且会把本来不长的倒计时挤进缩小字号档。
- 倒计时是结构化数据（`known` / `expired` / `text`），渲染分支只读标志位，不比较中文文案。
- 时间戳已过而新数据未到时，环内显示 `0s`，说明文字提示即将刷新；不在前端猜测下一轮额度。
- 任一显示的额度窗口进入最后一分钟时，每秒刷新倒计时；其他时候保持 30 秒的显示刷新节奏。宿主数据轮询与此显示定时器相互独立。

## 视觉与验收

- 凹槽上沿有内阴影，抬起的中心盘有边缘高光；明暗主题都能看出轨道层次。颜色只辅助区分用量档位，弧长、时间与展开数值始终保留。
- 中心字号分三档而非两档：≤3 字符 12px、4 字符 10.5px、≥5 字符 9px。两档时 `1h0m` 到 `59m` 会让数字突然变大，每小时抖一次；省略零单位后 `1h` → `59m` 全程 12px。
- 凹槽材质随尺寸递减：46px 环保留三层凹槽与内盘高光，22px 状态环只留单层内阴影加一圈发丝高光——那几层高光在小尺寸下只会把边缘糊成灰雾。
- 尊重 `prefers-reduced-motion`，动画关闭后数据仍正常更新。
- 29% 已用、2 分钟重置：收起环约 29% 彩色弧，中心 `2m`；精确 `29%` 只在悬停/聚焦说明中出现。
- 1% 已用：弧长按 4% 周长绘制，展开详情右侧仍显示 `1%`。
- 最后一分钟：`59s` 每秒递减至 `1s`；过期后显示 `0s`，直至服务端投影更新。
- 0%、75%、96%：弧长与五档颜色正确变化，0% 不呈现已用弧。
- 详情行不再重复百分比：MCP 行由环表示比例、右侧显示 `11 / 4k`，副标题只留重置信息。
- 时间戳已过时，详情副标题显示 `即将刷新` 独立成句，不再拼成 `即将刷新 后重置`。
- 有周额度时两枚环分别显示各自的倒计时；展开详情仍显示 MCP 次数与重置时间。
